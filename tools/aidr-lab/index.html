What this is

This library renders every record in data/test_dataset.jsonl from CrowdStrike's public aidr‑aiguard‑lab repository — a CrowdStrike‑curated test corpus used to evaluate the detector efficacy of the AIDR AI Guard API. Nothing in the prompt text, labels, or source fields has been altered; only a coarse detector group (below), plus dedicated PII and Topic facets, were derived for filtering.

Label taxonomy, per the repo's README

Benign labels: benign, benign_auto, benign_prompt, conform

Malicious prompt labels: malicious, malicious_auto, malicious_prompt, malicious‑prompt, prompt‑injection, prompt‑injection‑auto, adversarial_prefix, adversarial_suffix, direct, direct_auto, direct‑injection, indirect, injection, jailbreaking, multi‑shot, not‑conform, not conform

Topic labels (pattern topic:* / not‑topic:*): toxicity, self‑harm‑and‑violence, roleplay, weapons, criminal‑conduct, sexual, financial‑advice, legal‑advice, religion, politics, health‑coverage, negative‑sentiment, gibberish

The PII & sensitive data filter covers the confidential‑and‑pii‑entity and secret‑and‑key‑entity labels — also not named in the README passage above, but self‑explanatory entity‑detector labels present in the raw file. The Topic filter lists every specific topic:* value that actually appears in this copy of the file, each with its own count. Every record is placed into exactly one detector group using this priority order when a record carries labels from more than one family: malicious > PII > topic > other > benign. A handful of remaining labels (malicious‑entity, mcp‑validation, language, emoji, code) aren't named in the README and aren't PII or topic labels either — those stay in Other rather than being guessed at.

A small number of records (36 characters total, across a handful of prompts) already contain the Unicode replacement character (�) in the upstream file itself — almost certainly an apostrophe or similar punctuation mark that CrowdStrike's own data pipeline couldn't encode. Those characters are shown here exactly as they appear in the source, not guessed at or corrected.
